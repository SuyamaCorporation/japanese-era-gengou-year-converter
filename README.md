# 日本元号 ↔ 西暦 変換ツール

令和・平成・昭和・大正・明治の双方向変換ツール。

## 機能
- 元号 → 西暦 変換（元号選択 + 年数入力）
- 西暦 → 元号 変換（西暦年入力、境界年は複数表示）
- 範囲外入力時: 「この元号の範囲外です」と表示
- 数字以外入力時: バリデーションエラー表示
- 元号一覧表（読み・期間・天皇名・典拠）
